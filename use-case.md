
## User Case-01 Создание записи 
### Акторы
Пользователь, Система
### Предусловие
Пользователь открыл приложение 


### Основной сценарий (Happy Path)
1. Пользователь выбирает услугу. 
2. Система отображает мастеров, оказывающих выбранную услугу. 
3. Пользователь выбирает мастера. 
4. Пользователь нажимает кнопку "Продолжить". 
5. Система отображает доступные слоты выбранного мастера. 
6. Пользователь выбирает свободный слот.  
7. Пользователь нажимает "Забронировать". 
8. Система создает запись
9. Система отображает сообщение об успешном бронирование. 

### Альтернативный сценарий - Слот уже занят
**Предусловие:** два пользователя выбрали одного мастера и один и тот же слот.

7.1. Пользователь нажимает кнопку "Забронировать".  
7.2. Система определяет, что выбранный слот уже занят.  
7.3. Система не создает запись.
7.4. Система отображает сообщение: "Слот уже занят, выберите другое время". 
7.5. Система отображает обновленный список доступных слотов.  

### Постусловие 
Запись создана и отображает в списке заявок пользователя; слот мастера помечен как занятый.
