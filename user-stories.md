## US-01 Создание записи

Как клиент,я хочу самостоятельно записаться на услугу через систему,чтобы не обращаться в поддержку по телефону и сэкономить время.

## Acceptance Criteria
### AC-01 - Выбор услуг

**Given:** Пользователь открыл систему.  
**When:** Пользователь выбирает услугу.  
**Then:** Система предлагает мастеров, которые оказывают выбранную услугу.  

### AC-02 - Просмотр доступных слотов

**Given:** Пользователь выбрал услугу и система предлагает мастеров.  
**When:** Пользователь выбирает мастера.  
**Then:** Система отображает доступные слоты с датой и временем.

### AC-03 - Успешное бронирование

**Given:** Пользователь выбрал мастера и доступный слот.  
**When:** Пользователь нажимает кнопку «Забронировать».  
**Then:** Система создаёт запись, показывает экран подтверждения 
с датой, временем и именем мастера, и отправляет уведомление 
на email/телефон пользователя.

### AC-04 - Одновременное бронирование одного слота

**Given:** Два пользователя выбрали одного мастера и один и тот же слот.
**When:** Оба пользователя одновременно нажимают кнопку «Забронировать».
**Then:** Система создаёт запись только для того, чей запрос обработан первым 
(на основе блокировки слота), второй получает сообщение 
«Слот уже занят, выберите другое время», и обновлённый список слотов.
