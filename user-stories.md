## US-01 Создание записи

Как клиент,
я хочу самостоятельно записаться на услугу через систему, 
чтобы не обращаться в поддержку по телефону и сэкономить время.

## Acceptance Criteria

### AC-01 — Просмотр доступных слотов

**Given:** Пользователь открыл систему.  
**When:** Пользователь выбирает мастера.  
**Then:** Система отображает доступные слоты с датой и временем.

### AC-02 — Успешное бронирование

**Given:** Пользователь выбрал мастера и доступный слот.  
**When:** Пользователь нажимает кнопку «Забронировать».  
**Then:** Система создаёт запись и сообщает об успешном бронировании.

### AC-03 — Отсутствие свободных слотов

**Given:** Пользователь открыл систему.  
**When:** Пользователь выбирает мастера.  
**Then:** Система сообщает об отсутствии доступных слотов.

### AC-04 — Одновременное бронирование одного слота

**Given:** Два пользователя выбрали одного мастера и один и тот же слот.  
**When:** Оба пользователя одновременно нажимают кнопку «Забронировать».  
**Then:** Система создаёт запись только для одного пользователя, а слот становится недоступным для второго.
