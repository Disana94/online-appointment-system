# Online Appointment System

> 🎯 **Система онлайн-бронирования услуг**, позволяющая клиенту самостоятельно выбрать услугу, мастера и удобный временной слот — без звонков и ожидания ответа поддержки.

---

## О проекте

**Online Appointment System** — система для автоматизации процесса записи клиентов на услуги.

Клиент может самостоятельно:

* 🔎 выбрать необходимую услугу;
* 👤 выбрать мастера;
* 📅 выбрать удобную дату;
* 🕐 выбрать свободный временной слот;
* ✅ оформить запись.

Система должна упростить процесс взаимодействия клиента с организацией и сократить количество ручных операций при бронировании.
